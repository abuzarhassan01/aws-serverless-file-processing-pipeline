# 🚀 Event-Driven Serverless File Processing Pipeline on AWS

A robust, production-grade, event-driven data ingestion pipeline built on AWS using **Amazon S3, AWS Lambda (Python), IAM Least Privilege Security, Amazon CloudWatch Observability, and Amazon SNS Alarming**.
